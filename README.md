# E-Commerce Manual Testing Project

This repository contains manual QA testing documentation created for a simulated e-commerce feature update.

## Project Overview

A cart quantity management update was assumed to be released for the application. Functional and regression testing activities were prepared to validate the updated functionality and ensure existing features continued to work correctly after the release.

## Testing Scope

The testing scope includes:

- Cart functionality
- Product quantity management
- Cart calculations
- Cart badge updates
- Checkout workflows
- Login and registration
- Product search and filtering

## Testing Activities

- Functional Testing
- Regression Testing
- Negative Testing
- Manual Test Case Design
- QA Documentation

## Repository Structure

### Functional Testing
Contains detailed manual test cases prepared for validating the cart update functionality and related user flows.

### Regression Testing
Contains regression test scenarios created to verify critical application functionalities after the feature update.

### Bug Reports
This section may include sample bug reports documenting identified issues, reproduction steps, expected results, actual results, and severity levels.
